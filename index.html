Everyday genomics metrics

Monthly indicators that genomics is becoming part of everyday life, refreshed automatically. Data: data/<metric>.csv (columns date,value,source,notes). Static plots: plots/light/ and plots/dark/. Source on GitHub.

How to use this data: see SKILL.md (API endpoints, pandas and Vega-Lite examples; written so an AI agent can build charts from it).

Embed a live chart elsewhere with vegaEmbed pointing at any CSV below, or <img src=".../plots/light/<metric>.svg"> for a static one.
